¿Cómo funciona el módulo de Reservas y Salón?

Guía Operativa
  • Inventario físico de mesas: Configurá abajo cuántas mesas reales tenés operativas en el salón para 2, 3, 4 y 6 personas.
  • Descuento automático de cupos: Cuando un cliente reserva por la web para una fecha y turno (Almuerzo o Cena), el sistema descuenta la mesa adecuada en tiempo real bloqueando el turno ante falta de stock.
  • Gestión de estados: Marcá las reservas como "Completada" cuando asisten o "Liberar / Cancelar" si avisan cancelación para restituir la disponibilidad de inmediato.
